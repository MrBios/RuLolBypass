# RuLolBypass

Утилита для восстановления доступа к **League of Legends / Riot Games** в России, когда из-за блокировок провайдера клиент Riot пишет «Нет подключения к интернету», висит на вечной загрузке или выкидывает «Trying to reconnect» — хотя интернет работает.

## Как это работает

Блокировки чаще всего бьют по TLS-соединениям к основным диапазонам IP Cloudflare, где живут серверы Riot. Резервные диапазоны Cloudflare при этом обычно не тронуты, и любой edge-IP Cloudflare обслуживает любую зону.

Утилита:

1. Параллельно проверяет ~26 доменов Riot (вход, авторизация, конфиги, мессенджер, клиент, CDN, сайты)
2. Живость проверяется TLS-рукопожатием с правильным SNI (не пингом — Cloudflare ICMP не отвечает)
3. Если домен мёртв напрямую — параллельно прозванивает пул резервных IP Cloudflare и прописывает **самый быстрый** из них в `hosts`
4. Если домен работает напрямую — все перенаправления для него **убираются** (включая старые мёртвые записи)
5. Перед изменением создаётся бэкап `hosts.lolbypass.bak`, свои записи держит в маркированном блоке `# >>> lol-bypass manage >>>`
6. В конце сбрасывает DNS-кэш и показывает таблицу результатов

## Использование

1. Скачайте `LolBypass.exe` (или соберите из исходника: `build.bat`, нужен только встроенный в Windows `csc.exe` — ничего устанавливать не надо)
2. Запустите двойным кликом, согласитесь с UAC (нужны права администратора)
3. Дождитесь сводки и **полностью** перезапустите клиент Riot (значок в трее → ПКМ → Exit)
4. Когда блокировки отпускают — просто запустите ещё раз: утилита увидит, что всё работает напрямую, и уберёт свои записи

Режим только диагностики (ничего не меняет, админ не нужен):

```
LolBypass.exe -scan
```

## ⚠️ Важно — прочитайте

- **Это работает не в 100% случаев.** Эффективность зависит от провайдера и текущей волны блокировок.
- **Возможны лаги в игре.** Часть трафика идёт через резервные IP Cloudflare — задержки могут быть выше обычных.
- Но если ничего не помогает (VPN, DPI-обходчики и т.п.) — попробуйте, во многих случаях возвращает доступ.
- Утилита меняет **только** файл `hosts` и ничего больше (никаких драйверов, сервисов, реестра).
- Чат-порт 5223, который режется DPI, через `hosts` не чинится — для этого нужен DPI-обходчик (например, zapret с `--filter-tcp=5223 --dpi-desync=syndata`).
- Windows 10/11.

## Откат

Удалите из `C:\Windows\System32\drivers\etc\hosts` блок между `# >>> lol-bypass manage >>>` и `# <<< lol-bypass <<<` — или восстановите файл из `hosts.lolbypass.bak`.
