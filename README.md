Утилита для восстановления доступа к **League of Legends / Riot Games** в России, когда из-за блокировок провайдера клиент Riot пишет «Нет подключения к интернету», висит на вечной загрузке или выкидывает «Trying to reconnect» — хотя интернет работает.

> ⚠️ **Честно:** это работает не в 100% случаев и возможны лаги в игре. Но если ничего не помогает (VPN, DPI-обходчики и т.п.) — попробуйте, во многих случаях возвращает доступ.

## Как это работает

Блокировки чаще всего бьют по TLS-соединениям к основным диапазонам IP Cloudflare, где живут серверы Riot. Резервные диапазоны Cloudflare при этом обычно не тронуты, а любой edge-IP Cloudflare обслуживает любую свою зону.

Утилита:

1. **Параллельно** проверяет 26 доменов Riot (вход, авторизация, конфиги, мессенджер, клиент, CDN, сайты)
2. Живость определяется TLS-рукопожатием с правильным SNI — не пингом (Cloudflare не отвечает на ICMP)
3. Если домен мёртв напрямую — **параллельно** прозванивает пул из 28 резервных IP Cloudflare и прописывает **самый быстрый** (топ-3 перепроверяются повторными рукопожатиями)
4. Если домен работает напрямую — все перенаправления для него **убираются**, включая старые мёртвые записи, оставшиеся от других фиксов
5. Перед изменением создаётся бэкап `hosts.lolbypass.bak`
6. В конце сбрасывается DNS-кэш и печатается таблица результатов

## Скачать и запустить

1. Скачайте **RuLolBypass.exe** из [Releases](https://github.com/MrBios/RuLolBypass/releases/latest)
2. Запустите двойным кликом, согласитесь с UAC (нужны права администратора)
3. Дождитесь сводки и **полностью** перезапустите клиент Riot (значок в трее → ПКМ → Exit)

Когда блокировки отпускают — просто запустите утилиту ещё раз: она увидит, что всё работает напрямую, и уберёт свои записи.

## Команды

| Команда | Что делает | Права админа |
|---|---|---|
| `RuLolBypass.exe` | проверка + автоматическое исправление hosts | да (сама запросит UAC) |
| `RuLolBypass.exe -scan` | только диагностика, ничего не меняет | нет |

## Что именно меняется в системе

Только файл `C:\Windows\System32\drivers\etc\hosts`. Никаких драйверов, сервисов, задач, записей реестра. Все изменения — в одном маркированном блоке:

```
# >>> lol-bypass manage >>>
108.162.192.125	clientconfig.rpg.riotgames.com
...
# <<< lol-bypass <<<
```

## Откат

Любым способом:

- запустить утилиту, когда блокировок нет — она уберёт всё сама;
- удалить блок `# >>> lol-bypass manage >>> ... # <<< lol-bypass <<<` из hosts руками;
- восстановить hosts из `hosts.lolbypass.bak`.

## FAQ

**Это безопасно?**
Утилита с открытым исходным кодом (один файл `LolBypass.cs`), меняет только hosts и делает бэкап перед изменением.

**Антивирус ругается на exe.**
Это неподписанный бинарник — редкие эвристики на такое реагируют. Можете собрать его сами из исходника одной командой (`build.bat`), это гарантия, что внутри именно этот код.

**Почему в игре могут быть лаги?**
Часть клиентских соединений идёт через резервные IP Cloudflare, которые могут быть дальше от вас, чем основные. Игровой трафик (серверы матчей) при этом hosts не затрагивается.

**Чем это отличается от VPN / zapret?**
VPN гоняет весь трафик через чужой сервер, zapret обманывает DPI на лету. RuLolBypass просто указывает «мёртвым» доменам живые адреса — точечно, без фоновых процессов. Хорошо сочетается с zapret.

**Клиент зашёл, но нет друзей/чата.**
Чат ходит на порт 5223, который режется DPI — hosts это не чинит. Нужен DPI-обходчик (например, zapret с `--filter-tcp=5223 --dpi-desync=syndata`).

**Работает на macOS / Linux?**
Нет, только Windows 10/11.

## Ограничения

- Эффективность зависит от провайдера и текущей волны блокировок — не гарантировано
- Не чинит порты, режущиеся DPI (5223 и игровые)
- Если Cloudflare поменяет политику edge-маршрутизации, подход перестанет работать

## Сборка из исходника

Нужен только встроенный в Windows компилятор — ничего устанавливать не надо:

```bat
build.bat
```

Эквивалент вручную:

```bat
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:exe /out:RuLolBypass.exe /codepage:65001 /r:System.dll LolBypass.cs
```
