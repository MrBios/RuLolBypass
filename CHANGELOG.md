# Changelog

## [1.1.0] — 2026-11-19

### Возможности
- Списки доменов Riot и резервных IP Cloudflare вынесены в редактируемые файлы `riot_hosts.txt` и `cloudflare_ips.txt` рядом с exe (без них используются встроенные значения)

## [1.0.0] — 2026-11-19

Первый публичный релиз.

### Возможности
- Параллельная проверка 26 доменов Riot Games (вход, авторизация, конфиги, мессенджер, клиент, CDN, сайты)
- Проверка живости TLS-рукопожатием с правильным SNI (не ICMP)
- Автоматический подбор рабочего IP из пула 28 резервных адресов Cloudflare (параллельный прозвон, выбор самого быстрого с перепроверкой топ-3)
- Запись/удаление пинов в `hosts` в маркированном блоке `# >>> lol-bypass manage >>>`
- Удаление устаревших чужих пинов Riot-доменов (строки с мёртвыми IP)
- Автоматический откат записей, когда домены снова работают напрямую
- Бэкап `hosts` перед изменением (`hosts.lolbypass.bak`)
- Сброс DNS-кэша после изменений
- Режим `-scan`: диагностика без изменений, не требует прав администратора
- Диагностика чат-портов 5223 (EUNE/EUW) с подсказкой по DPI-обходу
- Журнал `lolbypass.log` рядом с exe

### Ограничения
- Не чинит порты, режущиеся DPI (5223 и игровые) — для этого нужны DPI-обходчики
- Эффективность зависит от провайдера и текущей волны блокировок
- Возможны повышенные задержки из-за маршрутизации через резервные IP
